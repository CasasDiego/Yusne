# Un jardín para Yusnecy

Una página de cumpleaños en español, con ilustraciones florales originales, una carta interactiva y diseño adaptable a móvil y escritorio.

## Foto de Yusnecy

Coloca su fotografía en `public/yusnecy.jpg` para mostrarla en el marco principal. Si todavía no se ha añadido, aparece una ilustración floral de reemplazo. La imagen se procesa en el navegador y no se carga a ningún servicio.

## Desarrollo

- `npm run dev` inicia el servidor local de Vite.
- `npm run build` comprueba TypeScript y genera la versión de producción en `dist/`.
- `npm run lint` ejecuta Oxlint.
- `npm run preview` sirve localmente la versión de producción.

La página no necesita dependencias de interfaz adicionales.
